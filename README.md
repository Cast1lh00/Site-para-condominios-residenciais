# 🏢 Site para Condomínios Residenciais

Projeto de um site de conveniência desenvolvido para apartamentos e condomínios residenciais, com o objetivo de centralizar recursos e facilitar o acesso a informações e serviços do ambiente condominial.

## 🎯 Objetivo

Desenvolver uma aplicação web voltada às necessidades de condomínios residenciais, utilizando tecnologias web e serviços de backend para estruturar os recursos do projeto.

## 🛠️ Tecnologias utilizadas

- **HTML, CSS e JavaScript** — desenvolvimento da interface web.
- **Firebase** — serviços de infraestrutura e hospedagem.
- **FullCalendar** — biblioteca para implementação de calendários e visualizações de eventos.
- **Git e GitHub** — versionamento e gerenciamento do código-fonte.
- **GitHub Actions** — automação do processo de publicação no Firebase Hosting.

## 📂 Estrutura do projeto

```text
Site-para-condominios-residenciais/
├── .github/
│   └── workflows/
├── public/
├── .firebaserc
├── .gitignore
├── firebase.json
├── package.json
├── package-lock.json
└── README.md
```

- `public/`: arquivos disponibilizados pela aplicação web.
- `.github/workflows/`: configuração de automação para publicação.
- `.firebaserc`: configuração de associação ao projeto Firebase.
- `firebase.json`: configuração do Firebase Hosting.
- `package.json`: dependências do projeto.
